# branding/

One place for the Eyemail mark, used by both surfaces so they can never drift apart.

| File | Used by |
|---|---|
| `app-icons/eyemail-icon.svg` | the source. Edit this one. |
| `app-icons/eyemail-512.png` | the web manifest, Play Store listing |
| `app-icons/eyemail-192.png` | the web manifest, Android home screen |
| `app-icons/eyemail-180.png` | iOS home screen (apple-touch-icon) |
| `app-icons/eyemail-96.png` | Android launcher (mdpi to xxhdpi scale from it) |
| `app-icons/eyemail-48.png`, `eyemail-32.png` | favicon |
| `app-icons/eyemail-1024-square.png` | Play Store, square, no rounding |

The mark is a blue gradient square with a white envelope, the same shape the app and the
web header already draw. Change the SVG, regenerate the PNGs, and both surfaces follow.
