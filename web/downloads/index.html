Install Eyemail

The Android app, the same mailbox as the web, on your phone.

Download the APK (17.7 MB)
  1. Open the file on your phone.
  2. Allow installing from this source if the phone asks.
  3. Install, then open Eyemail and sign in.

This is a debug build, for testing. If the phone refuses because an older version is installed, remove the old Eyemail first.
