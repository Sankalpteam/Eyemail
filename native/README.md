# native/

The Android app for Eyemail lives here.

Rules for this folder:

- The screens must match the web app exactly: same blue, same spacing, same words.
  Anything that looks different is a bug, not a design choice.
- One app, one package: `in.eyemail.app`.
- The web app in the repository root stays the source of truth for layout while the
  native screens are built, so the two can be compared side by side.

Structure is being decided by the owner and will be added here next.
